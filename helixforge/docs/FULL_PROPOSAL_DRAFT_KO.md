# HelixForge AI — 신약개발 멀티에이전트 워크벤치 (공모 제안서)
**버전** 1.0.0 · **생성** 2026-07-04T12:29:59.300037+00:00

> 본 시스템은 연구 의사결정 보조 도구이며, 전문가의 과학적·임상적·규제적·윤리적 검토를 대체하지 않습니다. 최종 판단과 책임은 연구자에게 있습니다.

### 출처 유형 범례
`REAL_TOOL_OUTPUT`(실제 도구) · `RECORDED_REAL_TOOL_OUTPUT`(기록 재생) · `CONFIGURED_BUT_NOT_RUN`(설정됨/미실행) · `TOOL_ERROR`(도구 오류) · `HEURISTIC_ANALYSIS`(휴리스틱) · `ASSUMPTION`(가정) · `BASELINE_MODEL_OUTPUT`(기준 모델) · `SAFETY_REDACTED`(안전상 편집) · `HUMAN_INPUT`(사람 입력)

## 1. 과제명
HelixForge AI: 실데이터 기반 자기수정형 멀티에이전트 신약개발 초기탐색 워크벤치

## 2. 한 줄 요약
실제 과학 도구(PubMed·ChEMBL·ClinicalTrials.gov·RDKit·TDC)에 연동된 17개 에이전트가 타깃·분자·안전성·임상/규제를 관찰 가능하게 연결하고, 오류를 스스로 교정하는 의사결정 보조 시스템.

## 3. 문제 정의 및 필요성
신약개발 초기탐색은 문헌 조사, 타깃 우선순위화, 후보 분자 큐레이션·검증, 독성·안전성 검토, 임상 선례 분석, 규제 리스크 평가가 서로 분리되어 있어 시간·비용이 큽니다. 각 단계는 도구·데이터·실패 양상이 달라 단일 프롬프트(챗봇)로는 통합·검증·자기수정이 어렵습니다.

## 4. 기존 초기탐색의 병목
- 문헌·데이터 파편화, 재현 어려움
- 타깃 선정의 근거 추적성 부족
- 후보 분자의 구조 검증·중복·활성 비교 부담
- 안전성/과장 표현 관리의 수작업 의존
- 임상·규제 리스크의 뒤늦은 발견

## 5. 제안 시스템 개요
목표를 방향성 있는 파이프라인(DAG)으로 분해하고, 결정론적 화학/데이터 작업은 로컬 도구(RDKit·TDC)로, 근거 조회는 공개 API로 라우팅합니다. Critic(비평) 에이전트가 오류를 탐지·수정하며, 모든 출력에 출처 유형을 표기합니다.

## 6. 분야 4 융합성
- **분야 1(타깃/가설):** PubMed·ChEMBL·ClinicalTrials.gov 근거 기반 타깃 점수화·가설 생성
- **분야 2(분자 후보/검증):** ChEMBL 활성 구조 확보 → RDKit 검증·디스크립터·다양성/스캐폴드 분석 → 투명 복합 점수
- **분야 3(임상/규제):** ClinicalTrials.gov 선례 요약 + 고수준 규제 체크리스트(휴리스틱, 문서 보조 가능)

## 7. 멀티 에이전트 아키텍처
Orchestrator + 16개 전문 에이전트, 16단계 DAG, Critic 자기수정 루프, 기록/재생(record/replay), 관찰 가능한 감사 로그. 내부 사고 과정(chain-of-thought)은 노출하지 않습니다.

## 8. 실제 도구 연동
- 실시간 HTTP: **PubMed·ChEMBL·ClinicalTrials.gov** (`REAL_TOOL_OUTPUT`)
- 로컬: **RDKit·TDC/PyTDC** (`REAL_TOOL_OUTPUT`)
- **AutoDock Vina·REINVENT4**: 설정 시 실행, 미설치 시 `CONFIGURED_BUT_NOT_RUN`으로 정직하게 표기(가짜 결과 없음)
- 최근 실행(기록 재생(recorded replay)) 기준 실제 도구 출력 —건, 미실행 —건

## 9. 과학적 타당성
- EGFR/NSCLC 회고적 재발견(retrospective rediscovery): —/5 기준 충족, 선정 타깃 EGFR(CHEMBL203)
- PubMed 근거 —건 · 임상 선례 —건 · TDC —행
- 분자 유효율 —, ChEMBL assay 품질 분석, 분자 다양성/스캐폴드/중복 분석
- 한계: in-silico 단계이며 습식 실험·임상 검증을 대체하지 않습니다.

## 10. 에이전트 자율성 및 자기수정
6종 오류 주입(잘못된 SMILES, 허위 인용, 도구 실패, 과장 표현, 안전 위험, 모순 근거)을 Critic이 탐지하여 before/after가 기록되는 수정을 수행합니다. 최근 자기수정률 —.

## 11. 평가 지표 및 evaluation set
도구 성공률, 인용 검증률(—), 분자 유효율(—), 자기수정률(—), 다중 시나리오 매트릭스(EGFR/BRAF/JAK2/PCSK9/TNF/ALK/KRAS/HER2), 리소스 효율성. 모든 지표는 실제 실행 상태에서 계산됩니다.

## 12. 비즈니스 및 사회적 가치
탐색·문서화 부담을 줄여 시간·비용을 절감(보수적 범위 추정)하고, 근거 추적성과 재현성을 높입니다. 습식·임상·규제 검증은 대체하지 않으며, 인간 검토가 필수인 지점을 명시합니다.

## 13. 리소스 효율성
결정론적 로컬 도구 + 공개 API, 캐시/재생을 통한 API 크레딧 절약, 부분 실패 허용. LLM 토큰 비용이 발생하지 않는 결정론적 기본 런타임.

## 14. 안전성 및 연구윤리
무합성경로 정책, 의료 자문 미제공, 인용 검증, AI 상호작용 원장(ledger), 출처 유형 거버넌스, 한국어·영어 안전/과장 린트, 인간 최종 책임 명시.

## 15. 구현 가능성 및 운영 계획
FastAPI 백엔드 + React 프런트엔드 + Docker로 즉시 실행·배포 가능. 저장소 계층은 Postgres 이식 용이. 기록 재생으로 오프라인 시연 가능.

## 16. 한계와 향후 계획
- 습식/임상/규제 검증 없음(주장하지 않음)
- Vina는 픽스처 기반, REINVENT4는 외부 설치 필요
- ADMET 예측 모델은 기준(baseline) 수준, 규제 RAG는 계획 단계
- 향후: 생성 루프 실연, 예측 모델 학습, 규제 문서 RAG, 리소스 라우터

## 17. 제출/시연 계획

## 18. 참고 자료 및 데이터 출처

## 부록: 기존 결정론적 백본에서 Fable 5 하이브리드 에이전틱 레이어로 확장 (Phase 7 델타)

HelixForge는 **결정론적 과학 검증 백본**에 **선택적 Fable 5 추론 레이어**를 추가했습니다. Fable 5는 과학적 사실을 생성하지 않으며(사실은 PubMed·ChEMBL·ClinicalTrials.gov·RDKit·TDC에서만), 다음 세 가지 고가치 추론에만 사용됩니다.

- **동적 계획(dynamic planning):** LLM이 실행 계획을 제안하고, 결정론적 검증기가 의존성·안전 규칙을 강제하며(합성/습식/투여량 단계 거부), 고정 스테이지가 폴백입니다.
- **근거 기반 가설 생성:** 제공된 evidence ID만 인용하는 보수적 가설을 생성하고, 허위/실패 인용은 제거, 각 문장은 언어 린트(+1회 안전 재작성)와 근거 등급을 통과합니다.
- **의미 비평(semantic critique):** 규칙 기반 비평 위에 LLM 비평을 얹어 미묘한 과장·근거 공백·출처 혼동을 잡아내고, 검증된 항목만 수정 이벤트로 변환합니다.

추가로: **LLM 투명성 원장**(모델·설정·비용·폴백 기록, 전체 프롬프트/CoT 미저장), **비용 라우터 + 예산 가드**(Fable는 고가치 단계에만), **record/replay 최종 Fable 스냅샷**(재생 시 라이브 호출 0), **true rediscovery**(알려진 약물 케모타입 회복 벤치마크), **안전 최적화 루프**(in-silico 선택/휴리스틱 생성, 합성 경로 없음).

**주장하지 않는 것:** 완전 자율 에이전트, 신약 발견, 효능/임상/규제 검증. API 키가 없으면 전체가 결정론적으로 동작하며 그렇게 표시합니다. 최종 판단과 책임은 연구자에게 있습니다.
