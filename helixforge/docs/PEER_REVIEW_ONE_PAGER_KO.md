# HelixForge AI — 1페이지 동료 검토 요약

> 본 시스템은 연구 의사결정 보조 도구이며, 전문가의 과학적·임상적·규제적·윤리적 검토를 대체하지 않습니다. 최종 판단과 책임은 연구자에게 있습니다.

**한 줄:** 실제 도구에 연동된 17개 에이전트로 신약개발 초기탐색을 관찰 가능하게 자동화하는 의사결정 보조 시스템 (챗봇 아님).

**실제 데이터:** PubMed·ChEMBL·ClinicalTrials.gov(실시간), RDKit·TDC(로컬). Vina·REINVENT4는 설정 시 실행.

**차별점:** 정직한 출처 표기 · 자기수정(자기수정률 —) · 근거 QA · 기록/재생(오프라인 데모 안전망) · 한/영 리포트.

**데모에서 보는 것:** 타깃 EGFR, 실제 출력 —건, 회고적 재발견 —/5, 분자 유효율 —.

**안전:** 합성 경로·의료 자문 미제공, 안전 린트(한/영), 감사 로그.

**한계:** in-silico 단계, 습식/임상/규제 검증 대체 불가.

**강조:** 실제 도구 + 정직한 출처 + 자기수정 + 오프라인 재생. 과장 없이 한계 명시.
