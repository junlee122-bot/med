# HelixForge AI — 공모 제안서 초안 (Field 4)

> 본 시스템은 연구 의사결정 보조 도구이며, 전문가의 과학적·임상적·규제적·윤리적 검토를 대체하지 않습니다. 최종 판단과 책임은 연구자에게 있습니다.

## 1. 개요
HelixForge AI는 자율 가설 생성, 도구 기반 분자 분석, 안전성/독성 스크리닝, 임상·규제 전략, 평가·감사 로그를 하나로 통합한 **멀티 에이전트 신약개발 의사결정 보조 시스템**입니다. 챗봇이 아니라 실제 도구(PubMed, ChEMBL, ClinicalTrials.gov, RDKit, TDC)에 연동되어, 모든 출력에 출처 유형(source type)을 표기하는 **관찰 가능한(auditable)** 시스템입니다.

## 2. 해결하려는 문제
신약개발 초기 탐색은 문헌 조사, 타깃 우선순위화, 후보 분자 큐레이션, 독성/안전성 검토, 임상 선례 분석, 규제 리스크 평가가 서로 분리되어 있어 시간·비용이 큽니다. 각 단계는 서로 다른 도구·데이터·실패 양상을 가지며, 단일 프롬프트로는 통합·검증·자기수정이 어렵습니다.

## 3. 분야 4 융합 전략
목표를 방향성 있는 파이프라인(DAG)으로 분해하고, 결정론적 화학/데이터 작업은 로컬 도구(RDKit, TDC)로, 근거 조회는 공개 API로 라우팅합니다. Critic(비평) 에이전트가 오류를 탐지·수정하는 피드백 루프를 갖춥니다.

## 4. 멀티 에이전트 아키텍처
Project Orchestrator + 16개 전문 에이전트(근거 마이닝, 인용 검증, 타깃 스카우트, 가설, 분자 설계, 화학정보 검증, ADMET/TDC, 결합, 합성 가능성, 안전성 감사, 임상 전략, 규제 검토, Critic, 평가, 리포트 작성). 각 에이전트는 계획·근거 요약·판단 근거·검증 체크·가정·불확실성·다음 행동만 노출하며, 내부 사고 과정(chain-of-thought)은 노출하지 않습니다.

## 5. 실제 도구 연동
- **실시간 HTTP**: PubMed(NCBI E-utilities), ChEMBL, ClinicalTrials.gov v2
- **로컬 실행**: RDKit(SMILES 검증·디스크립터), TDC/PyTDC(ADME/Tox 데이터셋)
- **정직한 상태**: AutoDock Vina·REINVENT4는 어댑터로 연동되며, 미설치 시 `CONFIGURED_BUT_NOT_RUN`으로 정직하게 표기(가짜 결과 없음).

## 6. 과학적 타당성
후보 분자는 실제 ChEMBL 활성 데이터에서 확보하고 RDKit으로 검증합니다. 가설은 검증된 PMID 근거에 연결되며 "in-silico 가설·전문가 검토 필요" 등 보수적 표현만 사용합니다. 타깃/분자 점수는 가중치·입력값·페널티가 모두 공개되는 투명 점수입니다.

## 7. 자율성과 자기수정
6종 오류 주입(잘못된 SMILES, 허위 인용, 도구 실패, 안전 위험, 과장, 모순 근거)을 통해 Critic이 오류를 탐지하고 before/after가 기록되는 수정(revision)을 수행함을 시연합니다. 데모 실행에서 자기수정률 1.0을 달성했습니다.

## 8. 평가
평가 벤치는 도구 통합, 근거 무결성, 분자 유효성, 에이전트 자율성, 리소스 효율성, EGFR/NSCLC 회고적 재발견의 6개 모듈로 구성되며 모든 지표는 실제 실행 상태에서 계산됩니다.

## 9. 비즈니스·사회적 가치
문헌 triage·타깃 우선순위화·후보 큐레이션·리포트 작성의 반복 부담을 줄여 탐색·문서화 시간을 절감합니다(보수적 범위 추정). 습식 실험·임상·규제 검증은 대체하지 않습니다.

## 10. 안전·윤리
출처 표기, 감사 로그, 안전성 게이트, 무합성경로 정책(no synthesis route), 인간 최종 책임 명시. 리포트는 내보내기 전에 안전 린트(safety lint)를 통과해야 합니다.

## 11. 실제 구현 가능성
FastAPI 백엔드 + React 프런트엔드 + Docker로 즉시 실행·배포 가능합니다. 저장소 계층은 Postgres 이식이 용이하며, 장시간 작업은 작업 큐로 확장 가능합니다.

## 12. 한계와 향후 계획
in-silico 의사결정 보조 단계이며, REINVENT4 실제 생성, TDC 예측 모델 학습, 규제 문서 RAG, 리소스 라우터 증류를 계획합니다.

## 13. 최종 책임
본 시스템은 연구 의사결정 보조 도구이며, 최종 판단과 책임은 연구자에게 있습니다.
