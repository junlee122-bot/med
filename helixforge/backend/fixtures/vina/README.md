# AutoDock Vina fixtures

Fixture-based docking integration. HelixForge ships a minimal prepared **ligand**
fixture (`sample_ligand.pdbqt`, benzene) for wiring/smoke tests.

## What you must provide

A prepared **receptor** PDBQT (`sample_receptor.pdbqt`) and a docking box.
Receptor preparation (protonation, charge assignment, PDB→PDBQT conversion, grid
box definition) is **out of scope** for this system and is flagged as future
work — it requires structural-biology expertise and tools such as
`AutoDockTools`/`meeko`. Prepare it externally and drop the file here.

Example (using Meeko + a PDB you have rights to use):

```bash
# Receptor prep is done OUTSIDE this app by a domain expert.
mk_prepare_receptor.py -i receptor.pdb -o sample_receptor.pdbqt
```

## Running

With the `vina` python package or the `vina` CLI installed (set `VINA_BIN`),
call `POST /api/vina/fixture-dock`. If Vina is not installed the endpoint returns
`CONFIGURED_BUT_NOT_RUN` — it never fabricates a docking score.

## Safety

Docking produces an in-silico **score only**. No wet-lab protocol, reagent list,
reaction condition, or synthesis route is generated by this system.
